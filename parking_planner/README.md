# 自动泊车路径规划系统算法逻辑梳理

## 一、系统概述

本系统实现基于**混合A\*算法**的自动泊车路径规划，输入障碍物多边形集合、起点位姿和目标位姿，输出平滑可跟踪的泊车路径。

**核心流程**：`障碍物/起终点 → 引导点提取 → 混合A*搜索 → 路径平滑 → 最终路径`

## 二、文件结构与职责

| 文件 | 职责 |
| ------ | ------ |
| `config.py` | 所有可调参数（车辆尺寸、搜索分辨率、代价权重） |
| `geometry.py` | 几何工具函数（距离、角度、车辆矩形构建） |
| `collision_checker.py` | 碰撞检测核心 |
| `svg_builder.py` | 模块1：可视图引导点提取 |
| `hybrid_astar.py` | 模块2：混合A*路径搜索 |
| `bspline_smoother.py` | 模块3：路径平滑 |
| `visualization.py` | 可视化绘图 |
| `main.py` | 主流程编排 |

## 三、各模块核心逻辑

### 1. 引导点提取（`svg_builder.py`）

- **输入**：障碍物多边形、起点位姿、目标位姿
- **流程**：提取障碍物顶点作为节点 → 构建可视图（节点间连线做碰撞检测）→ Dijkstra搜索最短折线路径 → 为路径节点分配航向角
- **输出**：引导点序列 `[(x,y,θ), ...]`

### 2. 混合A*搜索（`hybrid_astar.py`）

- **输入**：引导点序列、车辆运动学参数、障碍物
- **核心机制**：
  - 状态空间离散化（位置网格 + 航向角网格）
  - 运动基元扩展（前进/后退，不同转向角）
  - 代价函数 `f = g + h`：`g`含路径长度、换挡、转向变化惩罚；`h`包含到引导点距离和航向偏差
  - RS曲线加速：距目标5m内且航向偏差<30°时尝试直线连接
  - 反向搜索机制（从目标向起点搜索）
- **输出**：粗糙路径点序列

### 3. 路径平滑（`bspline_smoother.py`）

- **输入**：粗糙路径
- **流程**：线性插值生成密集点 → 滑动窗口平滑航向角 → 碰撞校验（若有碰撞则调整采样间隔重新插值）
- **输出**：平滑路径点序列（200~500个点）

### 4. 碰撞检测（`collision_checker.py`）

- 支持**线段碰撞**（可视图建边）和**车辆矩形碰撞**（搜索/路径校验）
- 使用 **Shapely** 进行几何运算，**STRtree** 加速空间查询

## 四、数据流向

输入数据
↓
[svg_builder] → 引导点
↓
[hybrid_astar] ← 引导点 + 障碍物 + 车辆参数
↓
粗糙路径
↓
[bspline_smoother] ← 粗糙路径 + 障碍物
↓
平滑路径
↓
输出路径 + [visualization] 可视化

## 五、关键参数（`config.py`）

| 参数 | 推荐值 | 说明 |
| ------ | -------- | ------ |
| 车辆尺寸 | 2.5m × 1.2m | 小型车 |
| 步长 | 0.3m | 搜索步长 |
| 位置分辨率 | 0.3m | 网格离散化 |
| 航向分辨率 | 10° | 状态空间大小 |
| 最大曲率 | 0.2 | 对应最小转弯半径5m |
| 搜索超时 | 60s | 防止死循环 |

## 六、可视化输出

- 灰色填充区域 = 障碍物
- 绿色/红色箭头 = 起点/终点
- 蓝色点 = 引导点
- 橙色虚线 = 粗糙路径
- 紫色实线 = 平滑后路径
