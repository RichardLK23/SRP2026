# SRP2026

## Identify.py

### 图像多边形检测系统 - 技术总结

#### 一、核心功能

检测黑底白图中的多边形，提取顺时针排序的顶点坐标，支持凸/凹多边形（五角星、L形等）。

#### 二、处理流程

输入图像 → 去除白边框 → 二值化 → 轮廓检测 → 多边形近似 → 合并共线点 → 输出顶点

#### 三、核心创新：共线点合并算法

问题

斜边上的点会被检测成多个顶点（如一条直线40个点），需要合并。
解决方案：迭代直线扩展

从点i开始 → 尝试扩展到i+2, i+3, ... → 检查中间点是否在直线上 → 都在则继续扩展 → 遇到偏离则停止 → 只保留端点

优势（修改调整后的成效）

    四边形：40点 → 4点（合并成功）

    五角星：20点 → 10点（精准保留所有角点，包括所有凸凹点）

    对噪声不敏感，参数直观（距离阈值）

#### 四、其他功能

    自动去除白色边框：从外向内的逐行检测

    动态多边形近似：自动搜索最佳epsilon值

    可视化开关：调试时看图，批量时静默

#### 五、调用方式

```python
polygons = detect_polygons('image.png')
```

返回: [[(x1,y1), (x2,y2), ...], ...]  # 每个多边形顺时针排序

#### 六、关键参数

参数 | 默认值 | 作用
|--|--|--|
epsilon_factor | 0.003 | 精度控制（越小点越多）
collinear_threshold | 5.0 | 共线合并灵敏度（像素）
visualize | True | 是否显示图表
